# Eishockey Gamecenter – Design-Prototyp

Klickbarer Next.js-Prototyp nach dem DEB-Briefing. Design: Weiß mit dezenter Trikotstruktur, Schwarz, Rot und Gold.

## Lokal starten

```bash
pnpm install
pnpm dev
```

Dann http://localhost:3000 öffnen.

## Umfang

- Responsive Startseite, Score-Leiste, Ligaübersicht, Matchcenter, Statistikcenter und Spielerprofil
- Klickbare Navigation und Tabs
- **Alle Spieldaten, Vereinszuordnungen und Statistiken sind ausdrücklich fiktive Demonstrationsdaten**
- Keine produktive Datenbank, Authentifizierung, CMS, Werbung, Live-API oder echte Videoanbindung

## Hinweis

Dies ist eine nicht-offizielle Designstudie, keine DEB-Veröffentlichung. Der Name und alle Daten dienen der Konzeptdemonstration.
